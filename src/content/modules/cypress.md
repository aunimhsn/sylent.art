Cypress est un framework de tests en JavaScript qui pilote une application web comme le ferait un utilisateur : il clique, remplit les formulaires et vérifie ce qui s’affiche. Des tests automatisés permettent de livrer plus souvent, avec moins de régressions. Ce module apprend à les écrire et à les lancer à chaque modification.
