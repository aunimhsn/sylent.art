Tailwind est un framework CSS qui remplace les feuilles de style écrites à la main par des classes utilitaires, posées directement dans le HTML. Il permet de construire vite une interface cohérente, sans chercher de noms de classes ni lutter contre une feuille de style qui grossit. Ce module en apprend la logique, de la mise en page au thème d’un projet.
