La programmation orientée objet (POO) est la façon d’organiser le code de la plupart des applications d’aujourd’hui. Elle découpe un programme en objets qui réunissent des données et les actions sur ces données, pour un code plus clair et plus facile à faire évoluer. Ce module en enseigne les notions en PHP, celles qu’utilisent ensuite les frameworks comme Laravel, et elles se transposent dans tous les langages objet.
